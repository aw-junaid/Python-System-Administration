# Notes:
# - psutil covers: cpu_info.py, memory_info.py, disk_info.py,
#   network_interfaces.py, boot_time.py, logged_in_users.py
# - distro is used (optionally) by os_version.py for accurate Linux

# - wmi is only needed by bios_info.py and motherboard_info.py, and
#   only on Windows. pip will skip it automatically on Linux/macOS.
# - installed_software.py, environment_variables.py, kernel_version.py,
#   and gpu_info.py use only the Python standard library and/or
#   OS-level command-line tools (dpkg/rpm, nvidia-smi, rocm-smi,
#   lspci) that are NOT installed via pip - they must already exist
#   on the host OS.
